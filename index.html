🔧 Arsitektur Integrasi QRIS Real-World (API / Webhook Payment Gateway) ▼

Untuk beralih dari versi demo ke produksi nyata, struktur JavaScript (app.js) telah siap dihubungkan dengan server backend / Payment Gateway (seperti DANA Enterprise, Midtrans, Xendit, atau Tripay):

  • Generasi QRIS Dynamic: Panggil API backend POST /api/qris/create dengan payload { amount, customerName } untuk mendapatkan String QRIS resmi dari Payment Gateway.
  • Verifikasi Otomatis (Polling / Webhook): Front-end akan melakukan polling periodik GET /api/qris/status/:txId atau menerima event WebSocket. Ketika server menerima Webhook callback dari DANA, status otomatis diubah menjadi Pembayaran Berhasil.
  • Keamanan: Verifikasi signature HMAC-SHA256 dilakukan di server Node.js/Express, bukan di browser client.
